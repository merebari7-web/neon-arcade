How the arcade works

  1. Pick a cabinet, then Open room. You get a 5-letter code.
  2. Send the code to whoever you want to beat. They choose join by code. Up to 8 in Snake, 1v1 elsewhere.
  3. Nothing to wait for: the room starts with a CPU rival the moment you hit start, and rounds auto-restart after each result.
  4. Leaderboards are server-side per game; solo scores are saved in your browser.
  5. No server? No problem. Solo cabinets run the identical rules engine locally in your tab.

Self-hosting this arcade

Everything here is plain Node + vanilla JS. Two commands and you have your own arcade with live rooms:

npm install
npm start        # then open http://localhost:3000

Deploy anywhere that runs Node and allows WebSockets (Render, Railway, Fly.io — configs are in the repo). The four solo cabinets also work as a pure static site on GitHub Pages, because the rules engine ships with the client.
